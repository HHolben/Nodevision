# Shared 3D model insertion

Insert → **3D Model** is available in HTML editing and Virtual World editing. It opens the existing Insert Media model form. **Notebook…** uses the existing shallow folder browser, **Choose File…** imports a local file, and **Download from Online Source…** opens the existing acquisition workflow. No recursive Notebook scan or separate GOX insertion menu is used.

HTML keeps the existing linked viewer, sizing, saved runtime, and legacy format behavior. GLTF/GLB, OBJ, STL, PLY and GOX use the existing rotatable Three.js viewer panel. GOX loads its original voxel source through the shared codec and renderer, preserving layers and colors. Existing USD and other format handling is retained.

World GLTF/GLB/GOX selections activate the same translucent preview. Move over a surface, left-click to place, or Escape/right-click to cancel. G opens source, position, rotation (degrees), scale, grid interval/snapping, surface snapping, pivot and ground alignment controls. Numeric placement is available in that dialog. Existing movement/look commands remain available outside the dialog. STL/OBJ/SCAD retain their existing object-file insertion path.

The inventory includes one **3D Model** tool. Equip it and use G to choose a source; placements repeat while equipped. G settings can also add a source-specific reusable inventory item. Assign items to slots with the existing inventory UI. Terminal `model.insert` opens the shared form; `model.world` accepts `choose`, `place`, `settings`, `commit`, `cancel`, `inventory`, `select`, `transform`, `duplicate`, `delete`, `edit-source`, and `reload`. Options include `path`, instance `id`, transforms, placement settings, and zero-based `slot` for inventory assignment. Rotation values in commands are radians.

Instances use the normal world layer list, picking, grab/gizmo/inspector tools, history, and save serialization. Their source, format, UUID, transforms, pivot, visibility and provenance persist. Inspector actions open the existing source editor, reload the source, duplicate, or delete. Reload preserves instance identity and transforms; failed reload retains existing geometry, and an initially missing source gets a red wireframe marker. Old `gox-model` definitions and GOX command aliases remain readable.

Implementation reuses `insertMediaModel.mjs`, the Notebook asset browser and binary save API, the existing Download/ResourceReference pipeline, bundled `GLTFLoader`, and GOX codec/cache/`VoxelScene`. Shared placement and instance lifecycle live in `public/Models/`. GLTF instances share source geometry/textures and own their materials and skeleton poses. Preview opacity therefore cannot alter placed instances. Source files are never rewritten by placement.

Scale 1 preserves glTF metre coordinates. GOX maps its Z-up axes into world Y-up and uses one metre per model voxel; terrain's 0.25 m voxel spacing is independent. Imported models do not carve terrain or create physics colliders. Animation playback and new decoder plugins are outside this integration; unsupported compressed assets report loader errors. Reload is explicit, not file watching. Single local GLTF imports with external companion files are rejected before save: place the complete source folder in the Notebook or use self-contained GLB. HTML's existing portable viewer uses its existing CDN runtime for other formats; GOX panels use Nodevision's bundled Three.js, OrbitControls, codec and renderer, so exported HTML requires those Nodevision modules to remain available. The browser regression substitutes bundled dependencies for other formats.

Validation extends `scripts/gox-world-browser.mjs` with shared toolbar/form, Notebook/local selection, GLTF/GLB/GOX preview/placement, history, resource sharing, picking/grab/gizmo lifetime, inspector/source actions, reload, inventory, missing-source recovery, acquired-resource provenance and completion, legacy references, HTML model rendering/reopening, and world serialization. Existing GOX View/Build, GLTF viewer, Voxel World insertion, and universal media workflow suites remain regression gates.
