# Focused construction editing — Phase 5

Choose **Edit Construction**, then **Edit Source** or **Make Unique**. Source geometry and `terrainVolumes` enter an isolated editing session. Existing Add, Brush, Erase, Paint, Pick and Revert tools affect only this construction. Ordinary temporary opinions remain stronger and are excluded from construction saves. World File Save retains references without publishing focused edits.

The native Inspect / Modify panel hosts construction controls. Add, duplicate, delete and activation changes create individual focused history transactions. Select a volume in the list, or enable **Edit volume handles** and click its box. Equipping a voxel tool or starting extrusion returns to geometry interaction. Drag a purple face handle to resize in integer steps; Alt-drag a handle to translate along that axis. Numerical position and size fields preview changes while typing; invalid input blocks commit, including any older valid proposal. Enter or pointer release commits; Escape cancels and restores displayed values. These keys work in the detached inspector as well as the world panel. Undo/redo cancels pending previews before applying history; pointer cancellation and focus loss cancel manipulation. Volume previews change runtime composition without modifying persistent definitions or the session baseline. Orange outlines show existing excavation, green outlines/cells show proposed excavation, and red cells identify geometry/terrain conflicts.

Shift-click occupied construction voxels to toggle selection, or use **Select All Construction Voxels**. E invokes the shared GOX extrusion controller; X/Y/Z constrain its world axis. Signed integer entry supports sequences such as E, X, -12, Enter. Pointer movement supports distance and automatic axis inference. Enter or left click commits; Escape or right click cancels. The shared `VoxelExtrusion` sweep supports irregular/disconnected selections and selects translated endpoints. Generated cells preserve source material identity and RGBA. One extrusion creates one geometry history transaction; it never expands excavation.

Geometry has no excavation-boundary constraint. Sparse baseline cells and edit opinions are serialized directly, without scanning their enclosing box. Transient cells outside procedural terrain extents receive a separate scene preview and construction collision bounds. Source geometry, volumes, scene helpers and temporary opinions remain distinct.

Before publication, all geometry/materials and volume definitions are validated. Geometry intersecting path-composed procedural occupancy outside active cuts blocks writes. Loaded instances following the edited source are checked at their individual placements, and inter-instance cut conflicts are checked. Add or resize a cut to resolve an intersection. Undo/redo restores geometry and volume composition; discard restores the saved baseline.

Edit Source preserves asset identity, filenames, volume identities, metadata, coordinates, instance identity and scene path. Make Unique writes a new pair of linked assets and relinks the selected instance while preserving placement. Output GOX groups semantic materials into layers and retains the existing world-to-GOX coordinate convention. Hidden/read-only GOX layers and non-grid-preserving transforms remain unsupported for focused editing.

Exact SHA-256 revisions protect conditional writes. Publication validates, checks revisions, writes GOX then definition, reloads and verifies both, and refreshes affected runtimes. A failed second write can leave a partially published pair: this is explicitly reported, edits remain available, and confirmed revisions allow retry. This API does not provide cross-file atomicity. Other worlds may reference the source; global reference discovery is unavailable. Explicit source-reload and Make Unique recovery remain supported.

Limits remain 65,536 occupied construction cells, 128 material groups, 64 MiB GOX, 16,384 cells per focused transaction, and 131,072 sparse opinions. Extrusion retains shared GOX preview limits of 4,096 steps and 262,144 source-cell visits; construction commits additionally obey the focused transaction limit. Excavation cell highlights sample at most 16,384 cells and report clipping; box composition is not clipped. Volumes remain axis aligned and unscaled. Capture retains its separate 512-cell axis and 1,048,576 sampled-cell limits. No performance evidence justified increasing these limits.

Phase 6 priorities: transactional linked-asset publication, global reference indexing and cross-world validation, profiling larger sparse operations, richer selection feedback and manipulation accessibility, and broader material-asset workflows. USD serialization, arbitrary rotations, mesh booleans, fluids and structural simulation remain excluded.
